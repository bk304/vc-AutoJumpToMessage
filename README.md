# AutoJumpToMessage

A Vencord plugin that automatically opens the channel where a new message was received.

Made for those who keep Discord open on a second monitor and want to quickly see new messages without manually switching to Discord.

By default, the plugin only jumps to new messages when the Discord window is unfocused, so it won't interrupt you while you're actively using Discord. Muted channels are also ignored.

[Instructions for installation](https://discord.com/channels/1015060230222131221/1257038407503446176)
